# Jilo

Программа студии видеопродакшена «Азия-Плюс». Убирает полосы и мерцание LED-экранов за спикером: бегущие горизонтальные или вертикальные полосы, «пульсацию» всего кадра, шум и пиксельную сетку экрана. Работает на Windows и Mac.

## Как пользоваться

1. Откройте Jilo и перетащите видео в окно (или нажмите «Открыть видео»).
2. Сразу видно «до/после»: тяните оранжевую ручку шторки по кадру. Ползунок внизу — выбор места в видео, стрелки ← → — по кадру, Shift+← → — по секунде.
3. Мерцание видно только в движении: кнопка **«В движении»** (или пробел) прокрутит 1–4 секунды «до/после».
4. Режим: **Мягко / Средне / Сильно**. «Средне» стоит по умолчанию и подходит для начала.
5. **«Обработать весь файл»** — результат сохранится рядом с исходником, исходник не меняется.

## Настройки

| Блок | Что делает |
|---|---|
| **Полосы экрана** | Главный фильтр. **Горизонтальные / Вертикальные** — направление полос. **Сила** — какую часть перепада убрать. **Потолок осветления** — насколько можно осветлить самую тёмную полосу: меньше — чище картинка, больше — лучше закрываются глубокие полосы. |
| **Шум и сетка экрана** | Сглаживает шум и пиксельную сетку только на экране, сильнее там, где были полосы. Спикера не размывает. |
| **Мерцание всего кадра** | Для случаев, когда «пульсирует» вся картинка (свет, лампы). Выравнивает общую яркость. По умолчанию выключено. |
| **Экран → Пипетка** | Синий экран Jilo находит сам. Если экран другого цвета — щёлкните пипеткой по его фону. |
| **Экран → Область** | Обведите экран рамкой — фильтр будет работать только внутри. |
| **Формат** | MP4 H.264 — обычный файл для монтажа и публикации. MOV ProRes 422 HQ — для дальнейшего монтажа и цветокоррекции, файл большой. |

Строка внизу превью подсказывает, что происходит: найден ли экран, на сколько поднимаются полосы, нужно ли взять цвет пипеткой.

## Установка

**Готовые установщики** (если собраны): Windows — `Jilo-Setup-1.0.exe`, Mac — `Jilo-macOS.dmg` (перетащить Jilo в «Программы»). На Mac при первом запуске: правый клик по Jilo → «Открыть» → «Открыть» (программа не подписана в Apple).

**Запуск без установки** (нужен Python 3.10–3.13, лучше 3.12):
- Windows — `Запустить Jilo (Windows).bat`
- Mac — `Запустить Jilo (Mac).command`

Первый запуск ставит библиотеки (несколько минут, нужен интернет), дальше программа открывается сразу.

**Собрать установщик самому:**
- Windows — `Собрать установщик (Windows).bat`. Результат в папке `dist`. Если установлен Inno Setup 6, получится `Jilo-Setup-1.0.exe`, иначе — готовая папка `dist\Jilo` с `Jilo.exe`.
- Mac — `Собрать приложение (Mac).command`. Результат: `dist/Jilo.app` и `dist/Jilo-macOS.dmg`.

**Автосборка на GitHub:** в репозитории есть `.github/workflows/build.yml`. После публикации тега `v1.0` GitHub Actions соберёт установщики для Windows, Mac Apple Silicon и Mac Intel и приложит их к релизу.

## Для разработчика

```
jilo/core.py      движок: фильтры, обработка файла
jilo/server.py    локальный сервер интерфейса (127.0.0.1)
jilo/app.py       окно программы (pywebview), перетаскивание, диалоги
jilo/ui/          интерфейс (HTML/CSS/JS)
jilo.spec         сборка PyInstaller
installer/        установщик Windows (Inno Setup)
```

Запуск в браузере для отладки: `python run_jilo.py --browser`.
